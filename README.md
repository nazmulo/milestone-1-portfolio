# 🌐 Personal Portfolio Website

A clean and responsive **Personal Portfolio Website** built using **HTML5** and **CSS3**. This project showcases a professional portfolio layout with sections for introduction, about, skills, resume, and contact information.

## 🚀 Live Demo

🔗 **Live Website:** [https://your-live-link.com](https://nazmulo.github.io/milestone-1-portfolio/)

---

## 📌 Features

* ✨ Responsive navigation bar
* 👋 Hero/Banner section with introduction
* 🙋 About Me section
* 💼 Skills showcase with technology cards
* 📄 Resume section (Education & Experience)
* 📬 Contact form with social media links
* 🎨 Modern and clean UI design
* 📱 Responsive layout using CSS

---

## 🛠️ Built With

* HTML5
* CSS3
* Font Awesome Icons
* Google Fonts (Open Sans)
